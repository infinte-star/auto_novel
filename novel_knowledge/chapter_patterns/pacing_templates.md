# 节奏模板库 (Pacing Templates)

---

## 一、章内节奏模板

### 标准四段式（适合大多数章节）
```
开场钩 (10-15%字数)：延续上章悬念/制造新冲突
    ↓
场景一 (30-35%)：主要事件推进
    ↓
场景二 (30-35%)：冲突升级/情感深化/信息揭示
    ↓
结尾钩 (15-20%)：爽点兑现+章末钩子
```

### 过山车式（适合高潮章/爽点章）
```
高开 (5-10%)：直接进入紧张场景
    ↓
攀升 (25-30%)：压力持续升级
    ↓
爆发 (30-35%)：正面对决/反转/爽点
    ↓
余韵+钩子 (20-25%)：反应+新悬念
```

### 呼吸式（适合铺垫章/感情章）
```
承接 (10%)：从上章平稳过渡
    ↓
日常/互动 (40%)：看似轻松的场景（但埋伏笔）
    ↓
微冲突 (25%)：打破日常的小事件
    ↓
暗流+钩子 (25%)：为下一个高潮蓄势
```

## 二、跨章节奏编排

### 三章一循环（基础节奏单元）
```
章 N  ：铺垫章（蓄势、埋伏笔、建立期待）
章 N+1：升温章（冲突加剧、压力增大）
章 N+2：爆发章（爽点兑现、反转、情绪高峰）
```

### 五章过山车（推荐的中等节奏单元）
```
章1：铺垫 + 小冲突（维持基础张力）
章2：事件升级 + 中钩子（期待感上升）
章3：压迫/困境（情绪最低点）
章4：反击/转折（爽点爆发）
章5：余韵 + 大钩子（收获+新期待）
```

### 十章弧线（一个完整的叙事弧）
```
章1-2：新局面建立 + 目标设定
章3-4：执行 + 遭遇阻碍
章5-6：困境加深 + 小失败
章7  ：转折点（新信息/新盟友/顿悟）
章8-9：反攻 + 高潮对决
章10 ：收束 + 下一弧伏笔
```

## 三、情绪节奏规则

### 张弛交替法则
- **不可连续3章高强度**：读者会疲劳
- **不可连续3章低强度**：读者会弃书
- 理想模式：高→中→低→高→中→低（波浪形）

### 情绪强度标注
| 等级 | 描述 | 适用场景 |
|------|------|----------|
| 5 | 极高（大高潮/大反转） | 卷末高潮、重大反转 |
| 4 | 高（爽点/紧张对决） | 打脸章、战斗高潮 |
| 3 | 中（稳步推进+微冲突） | 常规推进、日常冲突 |
| 2 | 低（缓冲/日常/感情） | 铺垫章、感情互动 |
| 1 | 极低（纯休整/过渡） | 弧线间过渡（不宜超过1章） |

### 强度分配建议
- 每10章中：5级×1, 4级×2, 3级×4, 2级×2, 1级×1
- 5级章节不能连续出现（审美疲劳）
- 1级章节只能出现1次且不能在弧线开头

## 四、特殊节奏模式

### 憋-炸-余韵（爽文核心三拍）
```
憋（2-3章）：主角被压制/被误解/被欺负
    ↓ （读者积累愤怒/期待）
炸（1章）：主角爆发/反杀/身份揭示
    ↓ （读者多巴胺释放）
余韵（1章）：围观者反应/对手崩溃/后续影响
```

### 信息揭露递进
```
线索1（第N章）：一个不起眼的异常
    ↓
线索2（第N+3章）：另一个异常，和线索1有关联
    ↓
拼图（第N+5章）：读者开始隐约猜到
    ↓
证实+反转（第N+8章）：真相揭示，但比猜想更深
```

### 双线交织
```
A线（主线）：主角行动线
B线（暗线）：反派/伏笔线（读者可能不知道）

A → A → A+B交叉 → A → B → A+B碰撞 → 爆发
```

## 五、卷级节奏

### 卷内结构
```
卷首章：新卷开篇（新地图/新对手/新目标）
  ↓ 3-5章铺垫+小爽点
中段：矛盾升级（连续打压+小胜利交替）
  ↓ 3-5章螺旋上升
高潮：卷末大战/大反转（全卷最强爽点）
  ↓ 1章收束
过渡：引出下卷悬念
```

### 卷间递进
- 每卷的冲突层级必须比上卷高
- 每卷的爽点强度上限必须比上卷高
- 世界观每卷扩展一层
- 主角能力每卷有明显跃升
