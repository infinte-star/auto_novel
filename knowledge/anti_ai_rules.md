# 去AI感规则库 (Anti-AI-Feeling Rules)

本文件整理自网文编辑/读者/平台审核反馈的 AI 文本特征，
以及经验证有效的对策。框架应在 writer prompt 和 style_health 中内化这些规则。

---

## 一、AI感五大致命特征

### 1. 华丽的空洞
- **症状**：堆砌形容词但无实质内容，"月光如水洒在..."
- **检测**：一段话删去所有形容词后，是否还有信息量？
- **对策**：每段必须推进至少一个信息点（剧情/人物/设定）

### 2. 逻辑跳跃
- **症状**：前一秒吵架，下一秒和好；角色突然知道不该知道的事
- **检测**：因果链是否完整？每个行为是否有动机？
- **对策**：场景转换必须有过渡，情绪变化必须有触发事件

### 3. 节奏均匀（最隐蔽的AI感）
- **症状**：每段差不多长、每个事件差不多的描写密度
- **检测**：标出每段字数，如果方差极小 = AI感
- **对策**：紧张段用短句（≤15字），平静段正常写，刻意制造长短交替

### 4. 角色同质化
- **症状**：所有角色说话语气相似，对话可互换
- **检测**：遮住角色名，是否能分辨谁在说话？
- **对策**：每个角色必须有独特的口癖/语言习惯/知识范围

### 5. 情绪直说（Tell not Show）
- **症状**："他很生气""她非常伤心"——直接用形容词定义情绪
- **检测**：搜索"很+情绪词"、"非常+情绪词"模式
- **对策**：通过动作/细节传达——"他捏着手机的手指发白"

## 二、AI高频违规词/句式（writer prompt 禁止清单）

### 必删词汇
```
值得注意的是、需要强调的是、不难发现、毋庸置疑、
综上所述、总而言之、由此可见、换句话说
```

### 限频词汇（每章≤1次）
```
然而、因此、此外、与此同时、事实上、
不禁、竟然、居然、赫然、蓦然
```

### 禁止句式
```
不是……而是……（连续使用）
首先……其次……最后……（论文式列举）
一方面……另一方面……
XX是……（定义句开头，连续使用）
```

### 限频标点
- 破折号（——）：每章 ≤ 3处
- 省略号（……）：每章 ≤ 5处
- 感叹号：每千字 ≤ 2个

## 三、AI结构惯性（必须打破的模式）

### 1. 总分总结构
- **AI默认**：开头概述→分点展开→结尾总结
- **修复**：开头直接进入事件，结尾用钩子而非总结

### 2. 对称排比
- **AI默认**：三段排比、对仗工整
- **修复**：刻意打破对称，奇数项好过偶数项，长短不一

### 3. 匀速叙事
- **AI默认**：每个事件相同描写密度
- **修复**：重要事件放大（3倍细节），次要事件压缩（一句带过）

### 4. 观察者叙述
- **AI默认**：上帝视角平铺直叙，旁观者式报告
- **修复**：贴紧 POV 角色，只写该角色能感知的内容

### 5. 情绪过饱和
- **AI默认**：情绪描写过于充沛，每次都满格
- **修复**：大部分时候克制，只在关键时刻爆发；"憋"比"放"更有力

## 四、正面技法（增加人感的方法）

### 1. 感官具体化
- 不说"环境很冷"，写"他呵出的气在空中凝成白雾"
- 五感交叉使用：视觉+听觉+触觉，不要只靠视觉
- 选择一个非常具体的细节（一只蚊子、一个水渍），而非泛泛描写

### 2. 对话个性化
- 每个角色有一个标志性语言习惯（口头禅/方言词/特殊用词）
- 对话中的潜台词：角色说的和想的不一样
- 对话节奏不均匀：有人话多有人话少，有人打断有人沉默

### 3. 叙述节奏差异
- 战斗/紧张：短句、动词密集、无形容词
- 日常/温馨：长句、细节丰富、可有少量形容
- 回忆/感伤：碎片化、意识流、句子不完整

### 4. 信息密度控制
- 不要每段都塞满信息（AI倾向于每段都"有用"）
- 允许"无用"的生活细节存在——这才是真实感
- 但"无用"细节必须服务于人物塑造或氛围

### 5. 不完美叙述
- 允许角色判断错误、理解偏差
- 允许叙述中有省略和跳跃（读者自行脑补）
- 刻意留白比刻意填充更有力

## 五、style_health 检测建议

以下可纳入 quality.py 的 style_health 检测逻辑：

### 现有检查（保留并强化）
- 破折号过多
- 重复句式
- 叙段过长

### 建议新增
1. **AI禁词密度**：统计上述禁词出现频率，超阈值告警
2. **段落方差检查**：计算各段字数的标准差，方差过小 = AI感
3. **对话区分度**：检测连续对话中是否有明显的语言风格差异
4. **情绪直说检测**：匹配"很/非常/十分 + 情绪形容词"模式
5. **开头环境描写检测**：章节前3句是否以环境物件为主语
6. **总分总结构检测**：章节首尾是否存在概括性语句

## 六、平台审核标准参考

### 番茄小说（2026年政策）
- AI粗制滥造 → 拒签/下架
- AI率高于40% → 直接拒稿
- 重点整治：格式混乱、结构失常、空洞水文、AI粗制滥造

### 晋江文学城
- 最保守：不允许AI生成叙事情节
- 只允许：校对/润色级别的AI辅助

### 起点中文网
- 允许AI辅助但需声明
- 编辑肉眼+AI检测双重审核

### 编辑识别AI的核心方法
1. 开篇大段环境描写 + 一句话形容词 > 3个
2. 前后人设矛盾（第一章父母双亡，后面给爸打电话）
3. 不推进剧情，只堆砌描写和内心独白
4. 文笔好但节奏坏（形容词华美但叙事无力）
