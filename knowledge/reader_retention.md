# 读者留存规则 (Reader Retention Rules)

---

## 一、弃书原因排行

### 最常见的弃书原因（按影响程度排序）

1. **连续多章无爽点/无进展**（最致命）
   - 3章平路 → 追读开始掉
   - 5章平路 → 大量弃书

2. **AI感过重**
   - 华丽空洞的描写
   - 逻辑跳跃/人设矛盾
   - 所有角色说话一个味
   - 被检测到 → 平台处罚

3. **节奏拖沓**
   - 过长的环境/心理描写
   - 不推进剧情的注水章节
   - 铺垫太长不给爽点

4. **人设崩塌（OOC）**
   - 角色做不符合人设的事
   - 为了剧情需要强行降智
   - 前后性格矛盾

5. **世界观太大驾驭不住**
   - 设定多但填充不了
   - 信息过载，读者记不住
   - 大量时间花在"介绍世界"而非"讲故事"

6. **感情线问题**
   - 三角关系处理不当
   - 感情进度太快或太慢
   - 为虐而虐

7. **金手指失控**
   - 太强导致无悬念
   - 太弱不像是金手指
   - 使用条件不一致

---

## 二、留存关键指标

### 追读率（章间留存）
- 衡量标准：读完本章的人有多少会打开下一章
- 影响因素：章末钩子质量
- 追读率下滑时检查：最近3-5章的结尾钩子是否做好

### 完读率（章内留存）
- 衡量标准：打开本章的人有多少读到最后
- 影响因素：章内节奏
- 完读率低时检查：章内是否有连续的无效段落

### 加书架率
- 衡量标准：访问作品的人有多少加入书架
- 影响因素：黄金三章质量 + 简介 + 书名

## 三、留存提升规则

### 短期留存（逐章）
1. 每章至少1个小爽点
2. 每章必有章末钩子
3. 每章开头3段内必须有事件/冲突/信息
4. 控制章内"无效段落"比例 ≤ 20%

### 中期留存（逐卷）
1. 每3-5章一个中爽点
2. 每卷一个大高潮
3. 卷与卷之间有承上启下的大钩子
4. 定期回收伏笔维持"啊原来如此"感

### 长期留存（全书）
1. 主角成长曲线要有明显的阶段性跃升
2. 世界观递进揭示（小世界→大世界→更大世界）
3. 核心悬念贯穿全书
4. 多条伏笔线的交织和回收

---

## 四、开篇留存特殊规则

### 前100字
- 事件密度 ≥ 3（首句是事件/动作/信息炸弹）
- 禁止环境描写开头
- 前3句主语不能是环境物件

### 前3章
- 第1章：冲突+主角出场+钩子
- 第2章：人设立体化+目标明确
- 第3章：金手指亮相+未来期待建立

### 第1-10章
- 情绪峰值间距：每章 ≥ 1个
- 钩子强度：最强级别
- 信息投放密度：每1000字至少1个新信息

---

## 五、数据驱动的节奏检查

### 如果追读率下滑
1. 回看最近5章的章末钩子 → 是否存在无钩子章节？
2. 检查最近5章的爽点分布 → 是否存在连续无爽点？
3. 检查最近5章的情绪走向 → 是否连续压抑无释放？
4. 检查是否存在大段无效描写 → 切割或压缩

### 如果完读率低（章内流失）
1. 检查章节开头 → 是否太平淡？
2. 检查章节中段 → 是否有超过500字的无事件段落？
3. 检查对话 → 是否有超过10轮的无效对话？
4. 检查整章 → 是否整章都在铺垫而没有任何回报？
