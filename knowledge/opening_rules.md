# 黄金三章 / 开篇规则 (Opening Rules)

黄金三章是免费平台的生死线。算法验证期首日约500流量，接住翻倍，接不住减半。

---

## 一、各章任务

### 第1章：冲突+主角+代入
- **首句必须是事件/动作/信息炸弹**，禁止环境描写开头
- 前3句主语不能是环境物件
- 首章出场人数 ≤ 4人（含主角）
- 主角必须在前300字内出场
- 核心冲突/困境必须在本章浮现
- 章末必须有强钩子（悬念/危机/反转）
- 用行动展示人设，不用形容词定义

### 第2章：人设立体化+情绪爆点
- 主角的性格多面性开始展现
- 第一个爽点必须在本章兑现（打脸/危机化解/系统首秀）
- 核心目标/动机明确化（读者知道主角想要什么）
- 至少一段高质量对话（展示声音差异化）

### 第3章：金手指亮相+长线期待
- 金手指/核心优势正式展示
- 世界观第一层揭示（但只揭一层，留更多层做悬念）
- 建立长线期待（更大的危机/更大的世界/更强的对手）
- 章末钩子必须是全书级别的大钩子

---

## 二、平台差异化

### 番茄/七猫（免费平台）
- 开篇像过山车，一上来就刺激
- 读者无沉没成本，划走就没了
- 书名必须包含流量关键词（重生/系统/开局/末日/穿越）
- 简介 = 核心卖点 + 爽点承诺，150字以内
- 前30字决定63%的留存率

### 起点/晋江（付费平台）
- 允许稍慢热，但第一章结束前核心冲突必须浮现
- 起点老白读者追求创新和深度
- 晋江读者追求情感铺垫的精细度
- 书名可以稍文艺，但不能模糊

---

## 三、开篇反模式（必须避免）

1. **环境描写开场**："晨光洒在山间……" → 直接劝退
2. **角色名堆砌**：首段出现5+名字 → 读者头晕
3. **非主角开篇**：配角视角开场 → 无法代入
4. **设定说明书**：大段介绍世界观 → 信息过载
5. **无冲突的日常**：平淡叙述主角的一天 → 无吸引力
6. **内心独白过长**：开篇大段心理描写 → 没有画面感
7. **欲望缺失**：读者读完第一章不知道主角想要什么 → 无驱动力

---

## 四、开篇公式

### 男频爽文公式
```
困境/屈辱 → 金手指激活 → 第一次小反击 → 更大危机预告
```

### 女频言情公式
```
身份反差/穿越触发 → 第一次CP互动 → 能力展示 → 关系悬念建立
```

### 悬疑/规则怪谈公式
```
诡异事件/规则呈现 → 主角被卷入 → 第一条规则发现 → 更大谜团浮现
```

### 系统流公式
```
主角落魄/困境 → 系统绑定 → 第一个任务完成+奖励 → 系统谜团暗示
```

---

## 五、信息密度要求

### 前1000字
- 至少包含：1个冲突 + 1个角色特征 + 1个悬念
- 信息投放密度：每500字至少1个新信息

### 前3章
- 已建立的要素清单：
  - [ ] 主角身份和处境
  - [ ] 核心冲突/困境
  - [ ] 金手指/核心优势
  - [ ] 至少1个配角（有记忆点）
  - [ ] 世界观第一层
  - [ ] 至少1个兑现的爽点
  - [ ] 至少1个长线悬念
  - [ ] 主角的核心目标/动机

### 第7章检查点
- 第7章是"追读门槛"——到这里还没建立稳定追读习惯的读者会流失
- 到第7章应额外完成：
  - [ ] 主角人设完全立住
  - [ ] 核心人际关系网络建立
  - [ ] 第一轮爽点循环完成（铺垫→高潮→余韵）
  - [ ] 至少一个次要悬念已解答（给读者"啊原来如此"的满足感）
